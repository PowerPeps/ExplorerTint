# ExplorerTint

Rajouter une coloration différente pour les noms des fichiers/dossiers dans l'explorateur selon qu'ils soient dans le .gitignore ou non.

À terme : d'autres modifications visuelles de l'explorateur du même style.

## Idées

- Liseré vertical coloré au bord gauche de la ligne pour marquer l'état Git, le nom gardant sa couleur normale.
